# Findings — UI (Calculator web app)

### Findings of UI-BASE-01 — design baseline and measured contrast (2026-10-22)
- (a) **UI** [topic: design-system, ui-accessibility] [type: debt] [target: UI-SCAF-01] — `tokens.css` must follow DESIGN.md, not the earlier palette: light `--color-focus` is `#b45309` and both dark blocks (`:root[data-theme="dark"]` and the `@media (prefers-color-scheme: dark)` block) must declare `--color-focus: #f59e0b` explicitly — without the declaration the dark themes inherit `#b45309`, which still passes 3:1 on the dark surface (3.44:1), so only a declaration check catches it; `--color-display-danger: #ff8a80` is declared in all three blocks. Proof: `python3 docs/state/archive/runs/RUN-M0-1/evidence/contrast.py DESIGN.md --css frontend/src/shared/styles/tokens.css` exits 0 (it fails on a missing or extra token, a diverging dark block, a later `:root` override and colour tokens outside the three blocks).
- (b) **UI** [topic: design-system, ui-accessibility] [type: debt] [target: UI-SCREEN-01] — The screen applies DESIGN.md: error copy and its marker inside the display use `--color-display-danger` (the light `--color-danger` measures 2.76:1 on the light display panel); a 3px `:focus-visible` outline with 2px offset on every focusable control; key hover/active fills `color-mix(in srgb, <fill>, var(--color-text) 8% / 16%)`; the checked theme segment uses the operator fill and weight 600; theme segments, history summary, rows and `Clear history` at least 48 × 48 px; busy dims only the value digits (the `≈` marker dimmed to 0.6 would measure 3.37:1 / 3.01:1); «The Keypad Budget Rule» (≤ 20 px padding plus border per side around the keypad). After the screen exists, Impeccable `document` runs in scan mode to refresh DESIGN.md and `.impeccable/design.json` from the shipped CSS.
- (c) **UI** [topic: design-system, live-verification] [type: verification] [target: UI-SCREEN-01] — The display size budget in DESIGN.md is an estimate (tabular digits taken as 0.6 em): verify in the real browser that a 10-character xl value and a 16-character lg value, each with the `≈` marker, fit on one line at 320 px and in the 22.5rem column (the lg case has about 4 px to spare), and that longer values wrap without truncation.
- (d) **UI** [topic: design-system, ui-accessibility] [type: rule] — Rule as built: the design records are `PRODUCT.md`, `DESIGN.md` (frontmatter tokens are normative; colour key `<name>` = light `--color-<name>`, `<name>-dark` = the value of both dark blocks) and `.impeccable/design.json`. Two token values differ from the first palette because a measurement failed (U5): light focus `#b45309`, display error colour `#ff8a80`. Every relied-on pair is measured by `contrast.py` (text ≥ 4.5:1, indicators ≥ 3:1, light/dark/system-dark).
